# 表单验证测试 Skill

## 适用场景
表单填写 / 信息提交 / 数据校验 / 设置页面 / 个人信息编辑

## 测试场景
- 输入框字符长度限制
- 特殊字符输入处理
- 数字/字母混合输入
- 表单提交成功/失败
- 表单重置功能
- 下拉选择/单选/多选
- 日期选择器
- 图片上传

## 测试要点
1. 先识别表单中的必填字段（通常有 * 标记或红色提示）
2. 验证输入框的 maxlength 属性，测试边界值
3. 提交前确认所有必填字段已填写
4. 注意日期选择器可能需要滑动操作
5. 图片上传需要访问系统文件选择器
6. 下拉选择可能使用 picker 或弹窗形式

## 检查点
- 超长字符截断或提示
- 特殊字符正确转义
- 提交成功显示成功提示
- 提交失败显示错误提示
- 必填字段为空时显示验证错误
- 修改后数据正确保存

## 常见问题
- 表单过长需要滚动 → 分段填写和验证
- 日期选择器难以定位 → 使用坐标点击或按键操作
- 文件上传弹窗不可控 → 使用固定测试图片路径
- 提交后无响应 → 检查 Loading 状态，增加等待时间
- 重复提交 → 提交后等待按钮恢复

## 断言策略
- 提交成功：assertVisible("保存成功") 或 assertVisible("提交成功")
- 字段验证：assertVisible("不能为空") 或 assertVisible("格式不正确")
- 长度限制：assertVisible("最多输入") 或 assertVisible("超出限制")
