# 注册测试 Skill

## 适用场景
用户注册 / 账号创建 / 信息填写 / 手机号注册 / 邮箱注册

## 测试场景
- 正常注册（完整信息提交）
- 必填字段验证
- 密码强度校验
- 手机号格式校验
- 验证码发送/验证
- 用户协议勾选
- 注册成功跳转

## 测试要点
1. 先填写必填字段，再选填字段
2. 手机号输入框通常只接受数字，需确认键盘类型
3. 验证码按钮通常有冷却时间（60秒），需等待
4. 密码确认字段需与密码字段一致
5. 用户协议勾选框必须在提交前勾选
6. 注册完成后等待页面跳转或弹窗

## 检查点
- 注册成功跳转到引导页
- 必填字段为空时显示错误提示
- 密码强度不足时显示提示
- 手机号格式错误时显示提示
- 两次密码不一致时显示提示
- 未勾选协议时无法提交

## 常见问题
- 验证码发送按钮未就绪 → 等待冷却时间结束
- 手机号已有账号 → 准备测试用的未注册号码
- 密码强度校验过严 → 使用包含大小写+数字+特殊字符的密码
- 注册接口限流 → 多次注册时注意间隔时间
- 键盘遮挡底部字段 → 滚动页面到目标字段位置

## 断言策略
- 注册成功：assertVisible("欢迎") 或 assertVisible("引导")
- 字段验证：assertVisible("请输入") 或 assertVisible("格式错误")
- 密码强度：assertVisible("密码强度") 或 assertVisible("太弱")
- 手机格式：assertVisible("手机号格式") 或 assertVisible("请输入正确")
