# 导航手势测试 Skill

## 适用场景
页面导航 / 菜单切换 / Tab 切换 / 手势操作 / 返回/前进 / 抽屉菜单

## 测试场景
- 底部 Tab 栏切换
- 侧边抽屉菜单打开/关闭
- 页面返回（物理键/导航栏）
- 下拉刷新
- 上拉加载更多
- 页面间跳转和返回
- 深层页面返回首页
- 手势滑动操作（左滑删除/右滑收藏）

## 测试要点
1. 底部 Tab 栏通常使用 accessibility_id 定位
2. 侧边抽屉可通过从左边缘右滑打开
3. Android 返回键键码为 4，iOS 需要从左边缘右滑
4. 下拉刷新需从顶部向下滑动一段距离
5. 左滑删除需精确在列表项上滑动
6. 深层导航时记录页面栈，确保返回逻辑正确

## 检查点
- Tab 切换后页面内容正确更新
- 抽屉菜单正常打开和关闭
- 返回键回到上一页
- 下拉刷新触发加载动画
- 上拉加载更多数据
- 滑动手势正确触发对应操作

## 常见问题
- 抽屉菜单被遮挡 → 先关闭其他弹窗
- 滑动距离不够 → 增大滑动坐标范围
- 返回键失效 → 检查是否在首页或根页面
- 手势与列表滚动冲突 → 使用更精准的坐标定位
- 页面跳转动画未完成 → 增加等待时间到 2-3 秒

## 断言策略
- Tab 切换：assertVisible("目标Tab内容") 或 assertElementExists("选中Tab标识")
- 返回操作：assertVisible("上一页标题") 或 assertTextVisible("页面标识")
- 下拉刷新：assertVisible("刷新成功") 或 assertVisible("最新数据")
- 滑动操作：assertVisible("删除确认") 或 assertVisible("已收藏")
