# 搜索测试 Skill

## 适用场景
搜索功能 / 筛选过滤 / 结果列表 / 关键词搜索 / 语音搜索

## 测试场景
- 空关键词搜索
- 正常关键词搜索
- 搜索结果点击跳转
- 搜索历史记录
- 热门搜索词点击
- 搜索结果筛选/排序
- 搜索结果翻页/加载更多
- 搜索结果为空
- 清空搜索框

## 测试要点
1. 搜索框通常在页面顶部，使用 accessibility_id 定位
2. 输入关键词后需触发搜索（回车键或搜索按钮）
3. 搜索结果加载需要等待，检查 Loading 状态
4. 空结果页面通常有提示文字和推荐内容
5. 搜索历史通常保存在本地，需考虑清理
6. 搜索结果列表通常使用 RecyclerView/ListView

## 检查点
- 搜索结果正确显示匹配内容
- 空关键词显示搜索历史或提示
- 搜索无结果时显示空状态页
- 搜索历史正确记录和显示
- 搜索结果可正常点击跳转
- 筛选条件正确过滤结果

## 常见问题
- 搜索接口响应慢 → 增加等待时间到 10 秒
- 搜索结果未加载完 → 等待 Loading 消失
- 键盘遮挡搜索结果 → 先收起键盘再验证
- 搜索历史数据残留 → 测试前后清理数据
- 特殊字符搜索 → 注意转义和异常处理

## 断言策略
- 搜索成功：assertVisible("搜索结果") 或 assertElementExists("结果列表项")
- 空结果：assertVisible("没有找到") 或 assertVisible("暂无结果")
- 搜索历史：assertVisible("搜索历史") 或 assertVisible("最近搜索")
- 结果跳转：assertVisible("详情页") 或 assertVisible("商品详情")
