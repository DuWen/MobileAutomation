# 登录测试 Skill

## 适用场景
用户登录 / 账号切换 / 密码重置 / 第三方登录 / 验证码登录

## 测试场景
- 正常登录（用户名+密码正确）
- 错误密码登录
- 空用户名/密码提交
- 密码显示/隐藏切换
- 忘记密码跳转
- 记住密码/自动登录
- 第三方登录（微信/QQ/Apple）
- 验证码登录

## 测试要点
1. 先定位"登录"按钮，确认其 accessibility_id 或 text
2. 输入邮箱时，优先使用 input field 的 accessibility_id
3. 输入密码时，需确认密码字段是 password 类型（secure text entry）
4. 点击"登录"后，等待至少 3 秒确保页面跳转完成
5. 登录成功后，验证拿到的 token 或用户信息显示

## 检查点
- 登录成功跳转到首页
- 错误密码显示提示信息
- 空字段显示表单验证错误
- 输入框支持密码可见性切换

## 常见问题
- 登录按钮被键盘遮挡 → 先按返回键收起键盘
- 密码错误提示弹窗 → 截图记录错误信息
- 网络超时 → 等待 10 秒后重试一次
- 键盘遮挡输入框 → 滚动页面使输入框可见
- 多次错误登录触发验证码 → 先处理验证码弹窗

## 断言策略
- 登录成功：assertVisible("首页") 或 assertVisible("用户头像")
- 登录失败：assertVisible("密码错误") 或 assertVisible("账号不存在")
- 表单验证：assertVisible("请输入") 或 assertVisible("不能为空")
